## Ayub's Personal Portfolio
This is my Portfolio site, it allows me to contain all of my projects and experience-whilst staying professional and structured.

I built this using: html, css & javascript.

## Ideas surrounding the site

I wanted a minimalistic, simple site; using 2 complementary colours and a minimal amount of icons.

## What it includes

Project Showcase: highlights key builds with descriptions, tech stacks, and GitHub links.

About me: An overview of my background, roles, and skills.

Responsive: Optimised for viewing across desktop, tablet, and mobile devices.
